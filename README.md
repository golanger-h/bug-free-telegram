# Эмулятор датчиков температуры

Небольшой Python-проект для демонстрации обмена данными о температуре через MQTT. Издатель формирует сообщения для пяти зон склада, а подписчик получает их, считает статистику и подготавливает записи журналов.

## Требования

- Python 3
- Доступ к интернету: приложение использует публичный MQTT-брокер `broker.emqx.io:1883`

Установите зависимость:

```bash
python3 -m pip install paho-mqtt
```

Для запуска тестов дополнительно установите `pytest`:

```bash
python3 -m pip install pytest
```

## Запуск

Откройте два терминала в директории проекта.

В первом запустите подписчика:

```bash
python3 warehouse_emulator_subscriber.py
```

Во втором запустите издателя:

```bash
python3 warehouse_emulator_publisher.py
```

Издатель каждую 1,5 секунды отправляет сообщения для зон A–E в MQTT-топики `warehouse/zone-a/temperature` – `warehouse/zone-e/temperature` с QoS 1. Подписчик слушает соответствующий шаблон `warehouse/+/temperature`. 

Сообщения содержат идентификатор устройства, температуру, влажность, единицу измерения и временную метку. В части сообщений присутствует `alerts: true`, обозначающий аномалию. Данные генерируются случайно; значения температуры в сообщениях — `22.5` для обычного показания и `-5` для аномального.

## Файлы проекта

- `warehouse_emulator_publisher.py` — подключение к MQTT-брокеру и отправка сообщений.
- `warehouse_emulator_subscriber.py` — получение сообщений и обновление статистики.
- `parser.py` — генерация данных датчика, разбор JSON и проверка признака аномалии.
- `stats.py` — обновление и вывод статистики.
- `logs.py` — форматирование строк журнала и оповещений.
- `tests/` — тесты парсера, статистики и форматирования журналов.

## Тесты

Из корневого каталога проекта выполните:

```bash
python3 -m pytest
```

## Замечания

- Издатель и подписчик используют общий публичный брокер без аутентификации. Программа не предназначена для передачи конфидециальных данных.
- Сводка статистики выводится в консоль с интервалом 10 секунд.
